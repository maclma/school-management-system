🔧 TROUBLESHOOTING

Issue: Can't connect to frontend
  Solution: npm start (or node simple-server.js)

Issue: Backend not responding
  Solution: go run cmd/server/main.go

Issue: Login fails
  Solution: Check credentials (admin@school.com / admin)

Issue: Blank page after login
  Solution: Clear browser cache and localStorage

Issue: API errors
  Solution: Check browser console (F12) and network tab
